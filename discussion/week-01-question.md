title: "What is an agent harness?"
author: "Prerith Arunkumar (prerith2)"
---

When people describe AI agents, three things come up together: the prompt, skills, and the harness. The first two seem clear enough. A prompt is what I type. A skill looks like a packaged set of instructions for a particular kind of task.

The harness is the piece I cannot pin down. What is it, and what does it do that the other two do not?

Put concretely: if the same model received the same prompt and the same skill but ran inside two different harnesses, would the results differ? If so, what is the harness actually deciding? Whether it can see my files, which tools it can call, whether it gets a second try after an error, when it stops?

I would like a clear comparison of the three, ideally with one example where changing only the harness changes the outcome.
